# Thinking Healer — Prompting Style Guideline

## Required Inputs

- Client/Brand
- Website
- Post Format
- Design Style
- Topic
- Main Hook
- Supporting Line
- Key Points
- CTA
- Audience
- Visual Subject
- Mood
- Output Size

- Instagram Post 1080x1080
- Instagram Carousel
- Instagram Story
- LinkedIn Post
- Website Banner
- WhatsApp Creative

---

## Prompt Writing Rules

Always specify:
- emotional tone
- lighting
- composition
- typography mood
- realism level
- layout structure

Never use vague words like:
- attractive
- modern
- cool
- nice
