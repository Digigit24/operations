# Missing Analytics Checklist

- [ ] GMB 90-day performance baseline/export: Searches, views, calls, directions, website clicks, queries
- [ ] Instagram insights: Reach, views, watch time, saves, shares, follows, profile actions
- [ ] Facebook insights: Reach, engagement, clicks, leads
- [ ] Meta Ads report: Spend, impressions, CTR, CPL, leads, appointments, creative performance
- [ ] Google Ads report: Spend, keywords, calls, leads, CPL, conversion rate
- [ ] GA4 report: Sessions, source/medium, landing pages, conversions
- [ ] Google Search Console report: Queries, clicks, impressions, CTR, positions, index coverage
- [ ] Keyword ranking report: Local/organic rankings for P0 terms
- [ ] Lead and appointment report: Leads, calls, WhatsApp, booked consultations, procedures, sources
- [ ] CRM report: Lead stages, response times, conversion, lost reasons
- [ ] Call report / recordings summary: Calls, answer rate, qualified calls, bookings, missed calls
- [ ] Creative/content performance report: Best/low performers, hooks, formats, watch-time, saves/shares
