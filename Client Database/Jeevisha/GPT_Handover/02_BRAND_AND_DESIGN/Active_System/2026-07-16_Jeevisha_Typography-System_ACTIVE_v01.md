# Typography System

- **Primary family:** modern sans — Inter, Onest, Manrope, Satoshi or DM Sans.
- **Body:** same family at regular/medium weight; generous line height.
- **Festival/reflective:** Playfair Display or Cormorant, used sparingly.
- **Hierarchy:** one headline, one subheadline, body, CTA/footer; no more than three type sizes per creative.
- **Highlights:** only one or two words in Royal Blue or Healing Green.
- **All caps:** small labels/CTAs only.
- **Do not mix font packs.**
- **HTML warning:** the visual reference uses fallbacks and demonstrates hierarchy, not locked production rendering.
