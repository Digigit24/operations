# Production Dimensions

| Format | Size | Notes |
| --- | --- | --- |
| Instagram portrait/default | 1080×1350 | Preferred social format |
| Instagram square | 1080×1080 | Use when required |
| Instagram Story/Reel | 1080×1920 | Keep overlay text subtitle-safe |
| Instagram carousel | 1080×1350 or 1080×1080 per slide | One idea per slide |
| Meta ad | 1080×1350 or 1080×1080 | One hook, one CTA |
| LinkedIn | 1200×1500 or 1200×1200 | Professional variant |
| GMB/GBP image | 1200×900 (4:3) | 5–20% text coverage, small logo |
| Website banner | 1920×700 / 1920×800 / 1600×600 | Confirm breakpoint/crop |
