# Extraction Scope and Limitations

This handover is based on all files mounted in the current project plus File Library results returned by project-history search. File Library items are indexed when raw bytes were unavailable. No passwords, API keys, OTPs or account credentials were found or included.

The package intentionally excludes the original patient-identifiable GMB review screenshot; a redacted derivative is included. It does not include private patient files or infer approval where none was documented.

Some older project conversations, connector files, linked Canva/Figma/Drive assets and platform dashboards may be inaccessible. Their absence is recorded as a gap rather than guessed.
