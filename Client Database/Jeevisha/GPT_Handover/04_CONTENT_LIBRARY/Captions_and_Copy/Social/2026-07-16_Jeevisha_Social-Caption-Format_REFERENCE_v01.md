# Social Caption Format Reference

1. Open with a counter-intuitive patient reality.
2. Use short, separated lines.
3. Name overlooked functional symptoms.
4. Explain why patients delay.
5. Clarify the clinical concern without diagnosing the reader.
6. End with a restrained action line.
7. Add location and one booking number.
8. Use approximately five relevant hashtags.
9. Add a plain keyword block after hashtags for search context.
10. Avoid guarantee, fear and “best clinic” language.
