## Caption template (Master Brand Brain §4.11)
```
[Hook line — bold, specific, recognisable]

[2-3 lines of body — the reframe or insight]

```

## Rules
- 60–120 words ideal (200 max). Front-load the hook (IG truncates). Hinglish-fluent. **One CTA.** 5–8 hashtags max (never a long visible hashtag tail).
- Separate approved captions from drafts once real ones are written. GMB captions must be kept separate from Instagram/Meta captions (see `../../04_GMB`).
- ⚠️ No hashtag blocks or keyword blocks were finalised in the project — build these fresh.
