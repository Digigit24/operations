# CLIENT PREFERENCES — Nakshatra

⚠️ **No direct client feedback, approvals, or revision history exists in the project.** Everything below is strategy-team direction inferred from the brand documents, not client-ratified preference.

## Documented "never" rules the team treats as firm
- Never guarantee results / "100%" / "miracle".
- Never use fear or urgency ("biological clock", "don't wait", "limited slots").
- Never treat male infertility as invisible.
- Never publish identifiable patient content without written consent.
- Never run MTP / sexual-health as promotional content.
- Never ignore negative Google reviews.
- Never use bright/discount/countdown "retail" aesthetics.
- Never go silent — fast response in this category is a trust signal (escalate slow response as an ops issue).

Two voice systems exist (newer restrained vs. older warmer). The team should get the client to ratify the **newer Master Brand Brain voice** as governing. Until then, writers must not mix the two.
