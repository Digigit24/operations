# LOGO USAGE GUIDE — Nakshatra

## What it is
A horizontal lockup: a **magenta-to-purple gradient symbol** on the left + the **"NAKSHATRA" wordmark** in deep navy on the right. The symbol reads as a seated/meditative figure resolving into a **triquetra (trinity knot)** at the base — fixity, balance, a navigational "star/constellation" (the meaning of *Nakshatra*). A small ⓒ sits between symbol and wordmark.

## Usage rules
- **Clear space:** margin equal to the height of the symbol on all sides. Nothing intrudes.
- **Minimum size:** 28px symbol height on screen / 12mm print. Below this, use symbol-only.
- **Placement in creatives:** small, **bottom-right**, paired with the URL. Never large, centred, or animated.
- **Backgrounds:** full-colour logo on cream/white. On navy, use the **reversed** lockup (white wordmark, gradient symbol retained — magenta reads well on navy).
- **Never:** recolour the wordmark to anything but navy/white; stretch/skew; add shadow/glow/outline; place on a busy photo without a clear-space pad; rebuild the symbol in flat pink; pair with a third typeface.

## The magenta reconciliation
The logo's magenta is a **deliberate identity colour, not category pink.** The no-pink rule still applies to layout fields. Magenta may appear **only** inside the logo, plus *optionally* one restrained accent per campaign (a tick mark or short underline), used as sparingly as gold — never as a background, never dominant, never replacing teal on CTAs, never more than one accent use per creative.
