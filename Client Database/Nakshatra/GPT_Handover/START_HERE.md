# Nakshatra — Simplified Client Folder

This structure is intentionally simple. It is designed for daily agency use, not for enterprise document control.

## The four folders you will use most

1. **00_SOURCES** — untouched master references received from the project, client, website or AI.
2. **01_DESIGN** — logo, colours, fonts, design rules and image-prompting guidance.
3. **02_ASSETS** — approved posts, approved images, photos, videos, editable files and final exports.
4. **04_GMB** — all Google Business Profile rules, copy, images, published posts and performance.

The remaining folders hold content, campaigns, verified client facts, reports and old files.

## Important operating rule

- Do not edit files inside `00_SOURCES`.
- Put approved visual outputs inside `02_ASSETS`.
- Put campaign-specific working files inside `05_CAMPAIGNS`.
- Put GMB material only inside `04_GMB`, even when the same topic also appears on Instagram.
- Move replaced or rejected material to `99_ARCHIVE`; do not delete it.

## Active brand warning

The project contains both an older pink/lavender fertility style and a newer navy–gold–teal editorial style. The newer design system should be treated as the working direction unless the client confirms otherwise. Do not mix both systems in one creative.

## Basic file naming

Use:

`YYYY-MM-DD_Channel_Topic_Asset_Status_v01.ext`

Example:

`2026-07-16_Instagram_Low-AMH_Static_APPROVED_v03.png`

Recommended statuses:

- DRAFT
- CLIENT-REVIEW
- APPROVED
- PUBLISHED
- SUPERSEDED
