# Script Format Reference

Use one file per major script:
`YYYY-MM-DD_Client-Topic_Content-Type_Language_Platform_Size_Status_vNN.md`

Required fields: Script ID · Title · Topic · Pillar · Language · Format · Duration · Audience · Hook · Main script · CTA · Visual direction · Status · Approval evidence · Source · Date · Campaign · Notes.

Do not label a hook, carousel or video concept as a complete script. Medical scripts require clinician approval, source links, privacy/consent review and a disclaimer plan.
