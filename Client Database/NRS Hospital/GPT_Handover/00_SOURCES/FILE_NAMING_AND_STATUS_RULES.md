# File Naming and Status Rules

`YYYY-MM-DD_NRS-Hospital_Topic_Content-Type_Language_Platform_Size_Status_vNN.ext`  
Unknown date: `DATE-UNKNOWN_NRS-Hospital_Topic_Content-Type_Status_vNN.ext`

Asset statuses: RAW, DRAFT, PENDING_CLIENT, APPROVED, LIVE, REJECTED, SUPERSEDED, ARCHIVED.  
Idea statuses: USED, APPROVED_NOT_USED, DRAFT, UNUSED, REJECTED, DUPLICATE, NEEDS_REVIEW.

Never use final/final2/latest/corrected-final as approval or version control.
