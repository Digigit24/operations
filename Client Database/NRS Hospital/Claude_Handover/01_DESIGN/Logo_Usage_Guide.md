# LOGO USAGE GUIDE — NRS Hospital
Source: Step 02 §4. Logo file: `../02_ASSETS/01_Logos/nrslogo.png` (also copied here as `nrslogo.png`).

**The logo:** blue ring + green medical cross symbol; "NRS" blue wordmark; "HOSPITAL" green; tagline "NURTURE RECOVER & SECURE LIFE".

## Placement
Top-left in website header and most posts; top-center acceptable on story/reel covers. Do NOT embed inside hero art.
## Sizes
1080×1080 → 120–160px · 1080×1350 → 130–180px · 1080×1920 → 150–210px · Website header 150–190px desktop / 120–150px mobile.
## Clear space
Equal to the height of the "NRS" letter group on all sides. No text/icon/CTA inside it.
## Backgrounds — OK
Warm white · soft blue tint · soft green tint · clean low-contrast photo.
## Backgrounds — avoid
Busy photo · strong gradients · red emergency blocks · dark navy (unless a formal white/inverted version is created — **not yet made**).
## Strict do-not
No recolour · no stretch/skew · no shadow/glow/outline/gradient · no badge lockup (unless approved) · don't split symbol from text (unless client approves symbol-only).

⚠️ A white/inverted logo variant and vector (SVG/AI/CDR) source are **NOT in this pack** — request from client/designer.
