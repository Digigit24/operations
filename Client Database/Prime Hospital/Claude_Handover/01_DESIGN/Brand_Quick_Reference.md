# BRAND QUICK REFERENCE
## Prime Speciality Hospital
*Read this before starting any design work. Full detail lives in Full_Design_Guidelines.md.*

---

**Brand personality:** Trustworthy · Specialist-led · Calm and reassuring · Modern medical · Patient-friendly · Practical, not overdramatic · Local but premium · Procedure-confident

**Primary colours:**
- Prime Blue `#0057D9` — headlines, nav, CTA buttons, trust elements
- Prime Navy `#003B8F` — footer background, hover states
- Medical White `#FFFFFF` — dominant background (~55–60%)

**Secondary colours:**
- Prime Green `#0BAA2B` — checkmarks, healing cues, icons, success states
- Prime Dark Green `#067A1B` — green hover states
- Soft Clinical Grey `#F5F7FA` / Soft Blue Tint `#EAF3FF` / Soft Green Tint `#EAFBEF` — card/section backgrounds
- Emergency Red `#D64545` and Amber `#F5A623` — rare, emergency/attention use only

**Font system:**
- Headlines: **Poppins Bold / SemiBold**
- Body: **Inter Regular / Medium**
- Never more than 2 font families on one surface

**Logo placement:** Top-left by default (top-right for ads, top-center for formal announcements). Keep clear space equal to the height of the logo mark. Never stretch, recolour, or place over busy photos.

**Design style:** Clean grids, generous whitespace, rounded cards (12–16px radius), soft shadows, line-style icons (2px stroke, blue or green — never mixed on one icon), "Prime Care Strip" footer (deep blue bar + green circular icons + white contact text).

**Image style:** Editorial documentary photography — real hospital, real doctor, real (consenting) patients. Soft directional side-light, warm 3800K colour temperature, slight grain. Never stock photos, never fluorescent overhead lighting, never a smiling-doctor-with-clipboard pose.

**CTA style:** One primary CTA per surface — WhatsApp first ("WhatsApp for Consultation," green), then Call ("Call: +91-7447441426," blue outline). Never 3+ competing CTAs. Never urgency language ("limited slots," countdown timers).

**Important restrictions (banned in copy and imagery):**
- Words: world-class, cutting-edge, state-of-the-art, best, #1, revolutionary, compassionate, holistic, paradigm, guaranteed, excellence
- Claims: "100% cure," "risk-free," "no complications," "guaranteed recovery"
- Visuals: hospital exterior (unless specifically requested), graphic medical imagery, DNA helix, stethoscope-on-keyboard, surgeon pointing at CT scan, fake urgency stickers, countdown timers

**Preferred post dimensions:**
- Instagram/GMB square: 1080×1080
- Instagram portrait: 1080×1350
- Stories: 1080×1920 (keep content 250px clear of top/bottom)
- Website banner: 1920×800

---

## ⚠️ One thing every designer must know before starting

There is a second, conflicting colour/typography system described in the Master Brand Brain document (teal `#0E5B5E` + sage + serif headlines). **It has never been used in any actual deliverable** — the logo, the design system, and every real post use the Blue/Green/Poppins/Inter system above. Default to the system on this page. See `OPEN_QUESTIONS_AND_CONFLICTS.md` (Conflict 5) for the full picture, and flag to the PM if anyone asks you to build in teal/serif.
