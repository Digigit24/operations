## 12. Pre-Publish QA Checklist

Before accepting any generated creative:

**Brand check:**
- [ ] Prime Blue + Green palette used correctly
- [ ] Logo placed top-left with clear space
- [ ] Footer includes phone and website
- [ ] No banned words (best, guaranteed, #1, world-class)

**Design quality:**
- [ ] Text readable at thumbnail size
- [ ] No text overlapping faces/hair/hands
- [ ] Layout feels premium, not flyer-like
- [ ] Contact info is correct

**Medical/legal:**
- [ ] No outcome guarantees
- [ ] No "best hospital" or "100%" claims
- [ ] Disclaimer present if needed

**Brand voice:**
- [ ] Would Dr. Bhalerao say this to a patient?
- [ ] Specific over superlative?
- [ ] Numbers rather than adjectives?
