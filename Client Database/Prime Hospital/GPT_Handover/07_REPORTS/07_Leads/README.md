# Lead and Appointment Reports

No CRM export, call log, WhatsApp log, appointment register, source attribution or procedure conversion data was supplied.

Minimum lead ledger:
- lead ID (non-clinical identifier);
- date/time;
- source and campaign;
- service interest;
- contact action (call/WhatsApp/form/direction);
- qualified/not qualified;
- consultation booked/attended;
- procedure advised/booked/completed;
- revenue band if permitted;
- reason lost;
- consent/privacy status.

Do not include private patient health information in marketing reports.
