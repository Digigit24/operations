# Approvals

No formal approval artifacts were supplied.

For every asset/copy, save:
- content/asset ID;
- filename and version;
- reviewer names and roles;
- clinical approval;
- legal/compliance approval where needed;
- client approval;
- approval date;
- approved channels;
- expiry/review date;
- change notes;
- final publication URL.

Publication evidence is not the same as explicit client approval.
