# Logo Usage Guide

1. `02_ASSETS/01_Logos/DATE-UNKNOWN_Prime-Website-Logo_RAW.png`
2. `02_ASSETS/01_Logos/DATE-UNKNOWN_Prime-Logo-And-Footer-Artwork_RAW.png`

Neither file is labelled client-approved in the available history. A vector master and complete variant pack were not supplied.

## Placement

- Default: top-left.
- Formal announcement: top-centre.
- Ad with left-side headline: top-right may be used.
- Footer placement is a fallback when the top region is too crowded.

## Suggested width

- 1080×1080: 130–190 px
- 1080×1350: 150–220 px
- 1080×1920: 150–220 px
- Website/GBP thumbnail: visible but secondary to the message

## Clear space

Until a vector logo manual is supplied, keep clear space at least equal to the height of the main “P”/mark around the lockup.

## Safe backgrounds

White, soft grey, very light blue or very light green. A reversed/white logo variant is not available in this package and must not be improvised.

## Prohibited use

Do not stretch, crop, recolour, redraw, rotate, add unapproved shadows, place over a busy photo, repeat as a watermark or create a fake icon-only mark.

## Required client deliverables

Obtain SVG/PDF/AI masters, horizontal and stacked lockups, monochrome and reversed versions, icon mark, minimum-size specification and trademark/ownership confirmation.
