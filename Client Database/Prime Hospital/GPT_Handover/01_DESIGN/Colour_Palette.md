# Colour Palette

## Current working logo-derived palette

| Role | Name | Hex | Primary use |
|---|---|---:|---|
| Primary | Prime Blue | `#0057D9` | Headlines, CTA zones, trust elements |
| Primary dark | Prime Navy | `#003B8F` | Footer, high-authority panels, contrast |
| Positive accent | Prime Green | `#0BAA2B` | Checkmarks, healing/recovery cues, icons |
| Positive dark | Prime Dark Green | `#067A1B` | Small high-contrast accents |
| Base | Medical White | `#FFFFFF` | Dominant background |
| Neutral | Soft Clinical Grey | `#F5F7FA` | Background sections/cards |
| Tint | Soft Blue Tint | `#EAF3FF` | Informational panels |
| Tint | Soft Green Tint | `#EAFBEF` | Positive/benefit panels |
| Text | Charcoal | `#1C2430` | Main copy |
| Text secondary | Slate Grey | `#5E6B75` | Supporting copy |
| Emergency | Controlled Red | `#D64545` | True emergency/warning only |
| Attention | Soft Amber | `#F5A623` | Limited caution cue |

Suggested visible ratio: 55% white/soft grey, 20% blue, 10% green, 10% tints, no more than 5% red/amber.
