## Operating hashtag format

Use 5–10 relevant tags, mixing:
- brand: `#MillenniumWoods`, `#TechnoKids`;
- category: `#Preschool`, `#EarlyLearning`, `#PlaySchool`;
- local: only the approved locality, for example `#Wakad` or `#Marunji`;
- audience/topic: `#PuneParents`, `#PlayBasedLearning`.

Do not add unverified location tags or use a long spam block on GMB.
