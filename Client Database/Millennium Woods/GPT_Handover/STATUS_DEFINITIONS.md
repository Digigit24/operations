# Status Definitions

## Asset statuses

- `RAW` — unedited source material.
- `DRAFT` — work in progress; not approved.
- `PENDING_CLIENT` — ready for a client decision.
- `APPROVED` — explicit approval evidence recorded.
- `LIVE` — published/deployed with evidence.
- `REJECTED` — explicitly rejected; reason recorded.
- `SUPERSEDED` — replaced by a newer governed version.
- `ARCHIVED` — retained, not for current production.

## Content-idea statuses

- `USED` — developed into a script/caption/concept; not necessarily published.
- `APPROVED_NOT_USED` — approved but not published; none currently found.
- `DRAFT` — developed but not approved.
- `UNUSED` — source-backed idea not developed.
- `REJECTED` — explicitly rejected; none currently found.
- `DUPLICATE` — duplicate idea/file.
- `NEEDS_REVIEW` — blocked by facts, attribution or compliance.

## Fact labels

- `CONFIRMED` — direct authoritative client proof.
- `CLIENT_APPROVED` — written client approval.
- `LIVE_ON_WEBSITE` — displayed publicly; not automatically approved/correct.
- `PUBLISHED` — found on a public platform.
- `DRAFT` — proposed/project working text.
- `INFERRED` — reasoned conclusion, labelled as such.
- `CONFLICTING` — two or more incompatible versions.
- `UNVERIFIED` — no sufficient proof.
