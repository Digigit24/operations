# File Naming Rules

Use:

`YYYY-MM-DD_Client-Topic_Content-Type_Language_Platform_Size_Status_vNN.ext`

When the exact date is unknown:

`DATE-UNKNOWN_Client-Topic_Content-Type_Status_vNN.ext`

## Examples

- `2026-05-13_Millennium-Woods_Preschool-Readiness_Reel-Script_English_Instagram_DRAFT_v01.md`
- `2026-06-01_Millennium-Woods_A-Day-at-School_Carousel_English_Instagram_1080x1350_DRAFT_v01.pdf`
- `DATE-UNKNOWN_Millennium-Woods_Primary-Logo_English_MultiPlatform_1206x657_PENDING_CLIENT_v01.png`

## Rules

- Increment `vNN` for every material revision.
- Do not overwrite a client-approved/exported version.
- Use hyphens, not spaces, in governed production filenames.
- Record the original filename in the relevant index.
- Never use `final`, `final2`, `latest`, `corrected-final`, `new-one` or `use-this`.
- `APPROVED` requires written approval evidence.
- `LIVE` requires a published URL/date or platform evidence.
