# Brand_Quick_Reference.md — Gore Multispeciality Hospital

*Read this before starting any design work. Full system: `Full_Design_Guidelines.md`.*

## Brand personality
**Trusted · Warm · Clear.** Founder-led, culturally rooted, honest, community-facing. Never corporate, never cheap, never generic. Test: "If this could've been Aditya Birla's, Apollo's, or Varad's creative — it's wrong."

## Primary colours
| Name | Hex | Use |
|---|---|---|
| Trust Maroon | `#7A3438` | Headlines, founder content, brand anchor |
| Vitality Orange | `#F47B2B` | Family/paediatric warmth |
| Wellness Green | `#7AB840` | Preventive care, healing, success |
| Care Sky | `#5BB7DA` | Clinical/informational |
| Heritage Gold | `#C9A35E` | Premium, festival, senior wellness |
| Auspicious Red | `#DB2F25` | **Emergency CTAs only — never decorative, never full background** |

## Neutrals
Soft Cream `#FBF7EE` (default background) · Clinical White `#FFFFFF` (ultra-clinical only) · Charcoal `#1E1B1A` (text) · Stone `#776E63` (secondary text)

## Secondary colours
None beyond the above six brand colours + four neutrals. Never use more than 4 brand colours in one creative.

## Font system
- **English editorial/headline (serif):** Fraunces SemiBold/Bold — founder/brand moments
- **English modern headline (sans):** Onest Bold — service/ad/social posts
- **English body:** Inter Regular/Medium
- **Marathi headline:** Mukta Bold · **Marathi body:** Mukta Regular
- Never mix serif headline + serif body. One H1 per creative, always.

## Logo placement
- Top-left: educational/founder/editorial. Top-right: ads/offers. Footer-centred: carousels. Bottom-right translucent (70–80%): stories/reels.
- Minimum 12% clear space on all sides. Never over busy photography or a peacock-feather pattern. Never below 60px wide.

## Design style (5 Brand Modes — pick the one matching content, not preference)
1. **Editorial Trust** — Maroon+Cream+Gold — founder content, brand campaigns
2. **Family Warmth** — Orange+Sky+Cream — paediatrics, maternity, family physician
3. **Clinical Clarity** — Sky+White+Maroon accent — diagnostics, insurance, appointments
4. **Vital Action** — Red accent+Maroon+White — 24x7 emergency (Red = accent/button ONLY, never background)
5. **Heritage Wellness** — Gold+Green+Maroon — senior care, festival, Ayurveda

## Image style
Photorealistic Indian healthcare only. Cinematic side-light, shallow depth of field, natural Indian skin tones. Real Indian doctors/families — never Western stock faces, never cartoon illustrations. Always check AI-generated anatomy (fingers, eyes, limb count).

## CTA style
Rounded rectangle (8–12px radius), solid fill, no glow/border. Approved copy: "Book Appointment," "Speak to Dr. Gore," "WhatsApp Us," "Call 24x7 Emergency." Never: "Click here," "Buy now," "Limited time only," fake urgency.

## Important restrictions (compliance — non-negotiable)
- Never: cure/guaranteed/100%/painless/miracle/permanent-solution language, or unverifiable "best in..." claims
- Never: blood/gore, before-after photos implying cure, patient distress as marketing, children in distress, identifiable patients without consent
- Always: doctor's full title + credentials when named; written doctor consent on file for any creative using their name/photo
- Every creative footer must include the 24x7 emergency number

## Preferred post dimensions
Instagram square 1080×1080 (default daily) · Instagram portrait 1080×1350 (**Gore's default — higher reach**) · Story/reel cover 1080×1920 · LinkedIn 1200×1200 · Website hero 1920×800
