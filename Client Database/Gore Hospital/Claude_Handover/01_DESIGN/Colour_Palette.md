> Hex codes are estimated from the logo file; production designers should colour-pick from the original logo source (SVG/AI) to lock exact values — treat these as ±5 RGB approximation until a vector source is produced (see gap in `Logo_Usage_Guide.md`).

## Usage hierarchy
Dominant (60–70% of canvas) / Supporting (20–25%) / Accent (5–15%). Never more than 4 brand colours per creative.

## Pre-approved combinations
| Combination | Mode |
|---|---|
| Trust Maroon + Soft Cream + Heritage Gold accent | Editorial Trust |
| Vitality Orange + Care Sky + Soft Cream | Family Warmth |
| Care Sky + Clinical White + Trust Maroon accent | Clinical Clarity |
| Auspicious Red + Trust Maroon + Clinical White | Vital Action |
| Heritage Gold + Wellness Green + Soft Cream | Heritage Wellness |
| Trust Maroon + Wellness Green + Soft Cream | Editorial Wellness (ortho/general doctor intros) |

## Never combine
Auspicious Red as a background · Vitality Orange + Wellness Green dominant together (fast-food clash) · Care Sky + Heritage Gold dominant together (washes out) · any brand colour at full saturation as a flat full-page background · black backgrounds with any brand colour (use Charcoal only for text)

## Contrast/compliance notes
Trust Maroon on Soft Cream ✅ compliant · Care Sky on Clinical White ⚠️ may fail WCAG AA, use darker text overlay · Heritage Gold on Soft Cream ⚠️ low contrast, decorative use only, never body text
