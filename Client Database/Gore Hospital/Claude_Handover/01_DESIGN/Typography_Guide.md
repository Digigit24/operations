# Typography_Guide.md

## English typography
| Tier | Recommended | Fallback | Use |
|---|---|---|---|
| Editorial headline (serif) | Fraunces SemiBold/Bold | Cormorant Garamond Bold, Lora Bold, Playfair Display | Founder content, hero brand moments, editorial creatives |
| Modern headline (sans) | Onest Bold | Montserrat Bold, Poppins SemiBold | Service pages, ads, social posts, infographics |
| Body | Inter Regular/Medium | DM Sans, Source Sans, Manrope | All long-form text, captions, descriptions |
| CTA / button | Onest SemiBold | Montserrat SemiBold | All call-to-action language |
| Caption / metadata | Inter Regular (smaller weight) | DM Sans Regular | Footnotes, dates, locations, compliance text |

**When to use serif vs. sans:** Serif (Fraunces) for Editorial Trust and Heritage Wellness modes (gravitas, "hospital with heart and history"). Sans (Onest) for Family Warmth, Clinical Clarity, Vital Action modes (modern, accessible, mobile-ready). Never mix serif headline + serif body — always serif headline → sans body, or sans headline → sans body.

## Marathi / Devanagari typography
| Tier | Recommended | Fallback |
|---|---|---|
| Headline | Mukta Bold | Hind Vadodara Bold, Yantramanav Bold |
| Body | Mukta Regular | Hind Vadodara Regular |

Marathi needs slightly larger optical sizes than English. When pairing both languages in one creative: Marathi gets equal-or-greater visual weight, both use compatible weights, line-height for Marathi 1.5× (vs 1.4× English).

## Type sizing
| Element | Desktop | Mobile | Weight |
|---|---|---|---|
| H1 — Hero headline | 48–72px | 32–44px | SemiBold/Bold |
| H2 — Section headline | 32–40px | 24–28px | SemiBold |
| H3 — Subheadline | 22–28px | 18–22px | Medium/SemiBold |
| Body | 16–18px | 15–17px | Regular |
| Caption | 13–14px | 12–13px | Regular |
| CTA button | 16–18px | 15–16px | SemiBold |
| Footer text | 13–14px | 12–13px | Regular |

## Hierarchy rules
One H1 per creative, always. H2 ≈ 50–65% of H1 size. Use weight + colour (not size alone) to create hierarchy. Letter-spacing: tight (-1 to -2%) for large headlines, default for body, loose (+2-4%) for ALL CAPS/small labels. Line-height: 1.15 large display, 1.35–1.4 body English, 1.5 Marathi.

## Emphasis
**Bold** for the single most important word (sparingly). *Italic* almost never (reads weak in healthcare). Colour emphasis (Trust Maroon on Charcoal) instead of underline. Never shadows/glows/strokes on text.

## Text-length rules by creative type
| Creative type | Words visible |
|---|---|
| Photorealistic post, minimal text | 5–12 |
| Promotional/offer ad | 15–35 |
| Carousel cover | 4–10 headline + 1 supporting line |
| Carousel internal slide | 35–45 |
| Festival creative | 20–50 (incl. greeting) |
| Text Heavy 50% | 60–100 |
| Text Heavy 75% | 100–160 |
| Text Heavy 100% | 80–180 |
| Infographic | 6 callouts max, 4–8 words each |
| Doctor branding post | 25–40 total |
| Story/reel cover | Under 8 |
| GMB post | 30–80 |
| WhatsApp broadcast creative | Under 15 on-creative |
