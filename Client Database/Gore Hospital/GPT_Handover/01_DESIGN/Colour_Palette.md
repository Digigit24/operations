# Colour Palette

The values below were estimated from a raster logo and require final sampling from an approved vector master.

| Role | Name | Hex | Use |
|---|---|---:|---|
| Lead | Trust Maroon | `#7A3438` | Headlines, founder, primary CTA |
| Energy | Vitality Orange | `#F47B2B` | Family, maternity, paediatrics |
| Wellness | Wellness Green | `#7AB840` | Preventive care, Ayurveda, positive states |
| Calm | Care Sky | `#5BB7DA` | Clinical information, diagnostics |
| Premium | Heritage Gold | `#C9A35E` | Senior wellness, festivals, milestones |
| Urgent | Auspicious Red | `#DB2F25` | Emergency CTA only; never full background |
| Background | Soft Cream | `#FBF7EE` | Default warm canvas |
| Text | Charcoal | `#1E1B1A` | Primary body text |
| Secondary text | Stone | `#776E63` | Metadata/captions |
| Divider | Light Stone | `#E6DFD3` | Borders/dividers |

Use 60–70% dominant, 20–25% supporting and 5–15% accent. Use no more than four brand colours per creative. Verify WCAG contrast, particularly Care Sky/Gold on light backgrounds.
