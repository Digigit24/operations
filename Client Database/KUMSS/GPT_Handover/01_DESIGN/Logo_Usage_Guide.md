# Logo Usage Guide

`KUMSS logo.png` (642×539 px) is the only local logo master. It contains the symbol, wordmark, “Bright future begins here” tagline, Devanagari shloka and TM mark.

- Observed live use: yes.
- Explicit client approval: not found.
- Vector source / trademark proof: missing.
- Use full lockup for official surfaces; compact/icon variants only after approved vector derivation.
