# Typography Guide — NSP

## Philosophy
An editorial serif gives institutional weight. A clean sans gives contemporary clarity. A mono typeface grounds dates, times and metadata.

## Stack
| Role | Recommended | Fallback |
|---|---|---|
| Display / editorial headlines | Source Serif Pro | Lora, Georgia |
| Body / UI | Inter | system-ui, Arial, sans-serif |
| Metadata | IBM Plex Mono | Menlo, Consolas, monospace |

## Core scale
- H1: Source Serif Pro 600, 64–72px desktop, 36–42px mobile, tight letter spacing.
- H2: Source Serif Pro 500, 40–48px desktop.
- H3: Source Serif Pro 500, 28–32px desktop.
- Card title: Inter 600, 20–22px.
- Eyebrow: Inter 700, all caps, 0.12em letter spacing, Brain Teal.
- Body: Inter 400, 16–17px, 1.6–1.65 line height.
- Metadata: IBM Plex Mono 400, 13–14px.

## Rules
- One H1 per page.
- Do not skip hierarchy levels.
- Keep body line length under 70 characters.
- Never justify text.
- Underline only for links.
- Avoid all-caps body copy.
