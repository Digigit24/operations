# Logo Usage Guide — NSP

## Official logo
The production-ready logo currently available is:

`02_ASSETS/01_Logos/2026-05-26_NSP-Official-Logo_Logo_All-Platforms_APPROVED_v01.png`

## Description
Multi-colour woven-brain mark in a grey circular badge with “NEUROLOGICAL SOCIETY OF PUNE” around the upper arc.

## Placement
| Format | Placement | Size guidance |
|---|---|---|
| Website header | Top-left | 48px height desktop / 36px mobile |
| Website footer | Top-left | 64px height |
| Instagram square | Top-left or bottom-right | 120–140px square |
| Instagram portrait | Top-left or bottom-right | 130–150px square |
| Story/Reels cover | Top-left | 130–150px square |
| LinkedIn portrait | Top-left | 140–160px square |
| YouTube thumbnail | Bottom-right | 110–130px square; avoid duration overlay |
| Conference creative | Top-left with lockup | Min 160px square |
| Lecture slide cover | Top-right | 100–130px square |

## Clear space
Minimum clear space equals half the logo diameter on all sides.

## Do not
- Recolour the brain mark.
- Crop the logo.
- Stretch, skew, rotate, or distort.
- Place on busy photo backgrounds.
- Use the brain mark alone on external assets.
- Recreate the logo with AI.
