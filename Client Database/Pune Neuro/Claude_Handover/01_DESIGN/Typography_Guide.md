# TYPOGRAPHY GUIDE — NSP

**Philosophy:** editorial serif headlines + clean modern sans body. Serif = institutional weight; sans = contemporary clarity. All three families are open-source and embed without licensing concerns. Source: Design Instructions §5. ⬜ Type stack pending client confirmation (alternates available).

## Type stack
| Role | Font | Web fallback |
|---|---|---|
| Display / headlines | **Source Serif Pro** | Georgia, serif |
| Body / UI | **Inter** | system-ui, -apple-system, sans-serif |
| Mono (dates, data) | **IBM Plex Mono** | Menlo, Consolas, monospace |

## Rules (✅ LOCKED)
- One H1 per page. Never skip heading levels. Eyebrow (H5) sits above H1/H2.
- Body line length ≤ **70 characters**. Left-aligned, never justified.
- Body sits on Paper Cream / Cream White, never on accent colours.
- **Bold** sparingly (true emphasis only). *Italic* for Latin medical terms (*in vivo*, *Bell's palsy*), publication titles, quotes.
- ALL CAPS only for eyebrows at +0.10–0.12em. Never underline for emphasis (links only).
- Vertical rhythm on an 8px grid; section spacing in multiples (64 / 80 / 96 / 120).

## Optional motif
**Drop-cap** for long-form articles: first letter in Source Serif Pro at ~5× body, Brain Teal. Max one per piece.
