# LOGO USAGE GUIDE — NSP

**The logo:** multi-colour woven-brain mark in a grey circular badge; "NEUROLOGICAL SOCIETY OF PUNE" set in white around the upper arc. It is the brand's single permitted burst of colour. Source: Design Instructions §4.

**File status:** only a flat **1092×1092 JPEG** is on hand (`../02_ASSETS/01_Logos/`). ⬜ Request a vector (SVG/EPS) and transparent PNG from the client.

## Placement & size
| Format | Placement | Size |
|---|---|---|
| Website header | Top-left | 48px desktop / 36px mobile |
| Website footer | Top-left of footer | 64px |
| Instagram square/portrait | Top-left OR bottom-right | 120–150px |
| Instagram story | Top-left | 130–150px |
| LinkedIn post | Top-left | 140–160px |
| YouTube thumbnail | Bottom-right | 110–130px |
| Conference creative | Top-left (lockup w/ conference logo) | min 160px |
| Lecture slide cover | Top-right | 100–130px |

## Clear space
Minimum clear space on all sides = **half the logo's diameter**. No text/image/element enters this zone.

## Do NOT (✅ LOCKED)
- ❌ Recolour the brain mark (multi-colour IS the identity)
- ❌ Place on a busy photo background (use a clean panel/strip)
- ❌ Stretch, skew, rotate beyond 0°, or crop
- ❌ Remove the grey ring or the wordmark
- ❌ Use smaller than 32px height (web) / 72px (print)
- ❌ Use the brain mark alone (without ring + wordmark) on external assets — internal docs only
- ❌ Place the logo over the multi-colour brain in any composition

## Note on dark backgrounds
The full-colour logo reads beautifully on Ink Black `#0A0E1A` — use the full-colour version in dark footers and prestige/conference creatives.
