# Dev Mantra — Typography Guide

## Font Families
- **Headings:** Onest, weights 700–900
- **Body:** Inter, weights 400–600

## Sizing (at 1080px canvas)
| Element | Size | Weight |
|---|---|---|
| Headlines | 48–68px | 800–900 |
| Subtitles | 22–30px | 500–600 |
| Body text | 16–18px | 400–500 |
| Minimum (legal/footer only) | 12px | — |
| Footer text | 11–13px | 400 |

## Letter Spacing
Slight negative tracking on headlines: `-0.02em` to `-0.035em`.

## Content Density Rule
**Less content, larger fonts.** Always favor whitespace over cramming text. A slide should communicate ONE key idea. If text feels crowded, remove words — don't shrink the font.

## In AI-Generated Images (Infographic KB)
- Default: **no text** in generated images — Canva handles all headline/body/label copy.
- Exception: text that is structurally part of the object (road signs, flag labels, checklist items, dial labels). When used: Onest 700-900, white on dark or navy/cyan on white.

## LinkedIn Caption Typography Rules (from Brand Voice Skill)
- No bullet points in long-form captions — prose only.
- Bold only for carousel headers, never in captions.
- Straight quotes only — no curly/smart quotation marks.
- Maximum one em dash per post.
