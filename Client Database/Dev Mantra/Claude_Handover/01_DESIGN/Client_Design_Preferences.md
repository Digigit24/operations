### 1.4 Design Philosophy
Think *Economist magazine infographic* energy — precise, layered, surprisingly beautiful. Central visual anchors rotate: sometimes a dense data table styled like a Bloomberg terminal card, sometimes a bold illustrated map of India–US talent flow, sometimes a photorealistic desk scene with annotated data callouts overlaid. Never the same structure twice.

Typography is tight and editorial — large stat call-outs dominate. Gold accents appear as ruling lines, number highlights, and section dividers. Layouts should feel like they have gravity — information placed with intention, not scattered.

**Motion graphics:** Data that builds line by line, numbers that count up, maps that draw themselves.

---

### 1.5 ChatGPT Prompt Principle
Give ChatGPT: concept + key facts + color palette + her name + the feeling (how it should make someone stop scrolling). Never specify layout or composition — let ChatGPT's design sense fill that in.

---

### 1.6 Slide Series Approved (AI + Offshore Delivery Post)

- Slide 1: Cover hook — one image, one headline, nothing else
- Slide 2: What AI does vs does not do — clean infographic, no photorealistic image
- Slide 3: The Middle Layer — three-band cross-section diagram
- Slide 4: The Two Questions — pure typographic contrast
- Slide 5: The Close — photorealistic image + direct CTA

**Key design rule for carousel:** One idea per slide. One visual element — either a photorealistic image OR a clean diagram, never both. Text that breathes.

## SECTION 5 — UNIVERSAL RULES ACROSS ALL FOUR PROFILES

### 5.1 These Are Personal Brands — Not Dev Mantra
- Dev Mantra logo/name appears as a subtle footer credit only
- Each person's name and one-line specialty replace the brand mark as the primary identity
- Every graphic should feel like it belongs to that individual — palette, subject matter, audience must be unmistakably theirs

### 5.2 ChatGPT Prompt Philosophy (Finalised)
The key shift from the session:
- **Tell it:** Concept + Feeling + Key Facts + Palette + Name
- **Do not tell it:** Layout + Composition + Structure + Where to place elements
- Over-directing produces generic AI outputs. Under-directing with strong conceptual framing produces premium editorial results
- Give ChatGPT space to be creative — it has better design sense than any prompt writer specifying every pixel

### 5.3 What Makes Graphics Look AI-Generated (to avoid)
- Dark gradients + glassmorphic cards
- Glowing cyan/blue borders on everything
- Ambient color blobs everywhere
- Dark navy backgrounds as the default
- Everything floating on blue

### 5.4 What Makes Graphics Look Premium and Editorial (to use)
- White `#ffffff` or off-white `#f4f6fb` as default background
- Typography as the primary design element
- Thin 1px `#eeeeee` rules as row separators
- 4px left-border callout boxes (no rounded corners, no shadow)
- Flat solid bars in data charts (no gradients, no glow)
- Photorealistic images that look like editorial photographs, not stock photos
- Generous whitespace — if it feels tight, remove content before shrinking fonts

### 5.5 Carousel Design Rules (Finalised)
- **Canvas:** 1080×1440px (3:4 ratio) — locked for all carousels
- **One idea per slide** — non-negotiable
- **One visual element per slide** — photorealistic image OR diagram, never both
- **Break content across more slides** rather than cramming into fewer
- Text hierarchy: Onest 800 headlines, Inter 400–600 body
- Footer: devmantra.com or individual's name + devmantra.com on every slide

## SECTION 6 — DEV MANTRA BRAND PAGE DESIGN SYSTEM (Finalised)

### 6.1 Locked Color System
| Token | Hex |
|-------|-----|
| Dark bg start | `#060c18` |
| Dark bg mid | `#0d1e3d` |
| Dark bg end | `#1b3c6b` |
| Primary accent | `#00b4c8` Cyan |
| Brand blue glow | `#4a73c4` |
| White | `#ffffff` |
| Off-white | `#f4f6fb` |
| Body text | `#333333` |
| Muted footer | `#999999` |

### 6.2 White vs Dark Usage
- **70% of posts:** White dominant background
- **30% of posts:** Dark navy dominant (for data showcases, special announcements)
- Never flat solid blue — always the textured gradient recipe

### 6.3 India Market Entry Carousel — Design Decisions
- 8 slides, all dark navy for uniformity
- Glassmorphic metric cards on dark slides
- Numbered content blocks on white slides
- Cover slide: photorealistic full-bleed factory image with dark overlay — scroll stopper
- All photorealistic images given `rgba(6,12,24,0.80)` dark overlay to blend into the navy world
- Ambient glow `#4a73c4` at 20% opacity at corners of every slide

### 6.4 White Editorial Carousel System (Finalised after client feedback)
When the dark system looks "too AI-generated," switch to the white editorial system:
- Background: `#ffffff` every slide — no exceptions
- Headlines: `#1b3c6b` navy, Onest 800
- Body: `#444444` charcoal, Inter 400
- Accent: `#00b4c8` cyan — short rules, left borders, key number highlights ONLY
- Row separators: thin 1px `#eeeeee`
- Callout boxes: 4px left border cyan + `#f4f6fb` fill — no rounded corners, no shadow
- Charts: flat solid navy bars — no gradients, no glow, no 3D
- Style reference: McKinsey report · FT data feature · Bain case study slide
