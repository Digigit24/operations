# Dev Mantra — Logo Usage Guide

**Status: No actual logo files exist in this workspace.** This guide captures the *rules* for using the logo, extracted from `DEVMANTRA_DESIGN_RULES.md`. The logo file itself must be sourced from the client or a prior design tool (Canva/Figma) — see Missing Assets note in `02_ASSETS/01_Logos/`.

## Rules

1. The Dev Mantra logo is **rectangular** — never force it into a square container.
2. Use the logo's natural aspect ratio; add padding around it if needed.
3. When the logo is displayed, **do not** write "DEVMANTRA" or "Dev Mantra" as text next to or near it. The logo already contains the brand name.
4. Preferred placement: **top-right corner**, roughly 160–200px wide at 1080px canvas.
5. Minimum breathing room from edges: 20–30px margin.
6. If the logo is already shown elsewhere in a design, the footer only needs the website URL — no duplicate logo.

## Personal Brand Pages — Different Rule

For the four individual personal-brand profiles (Namrata, Vikas, Nidhi, Kamal), the Dev Mantra logo/name appears **only as a subtle footer credit**. Each person's name and one-line specialty is the primary visual identity on their own content — not the Dev Mantra mark. See `Client_Design_Preferences.md`.

## Canva Zone Convention (from the Infographic Prompt KB)

```
ZONE-LOGO: Dev Mantra logo | top-right | 30px margins
```
This is the standard placement instruction used when briefing carousel slide production.
