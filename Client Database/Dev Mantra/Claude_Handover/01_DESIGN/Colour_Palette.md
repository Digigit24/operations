## 1. Company Brand Page (Locked System)

| Token | Hex |
|---|---|
| Dark bg start | `#060c18` |
| Dark bg mid | `#0d1e3d` |
| Dark bg end | `#1b3c6b` |
| Primary accent (cyan) | `#00b4c8` |
| Brand blue glow | `#4a73c4` |
| White | `#ffffff` |
| Off-white | `#f4f6fb` |
| Body text | `#333333` |
| Muted footer | `#999999` |
| Warning/danger (sparing use) | `#cc1f2a` |
| Financial risk/alert (editorial thumbnails only) | `#c8890a` |
| Text dark (body on white) | `#222222` |

**White vs. dark usage split:** 70% of posts white-dominant, 30% dark-dominant. Never flat solid blue — always the gradient recipe above.
