## SECTION 0 — VISUAL CATEGORY RESEARCH

🟦 What the local SMB digital-marketing-agency category looks like visually in 2026:

### What competitors overuse
- Blue + cyan gradient backgrounds ("tech-y" cliché)
- Stock laptop-with-graphs hero shots
- "AI brain" silhouettes and circuit-board overlays
- Generic team-huddle / handshake stock photos
- 3D isometric dashboard illustrations
- Trophy / "Award-winning" badges with no actual award
- Megaphone, rocket, and "going up" arrow icons
- Purple → cyan AI gradient (the "ChatGPT" palette)
- Big number callouts in glowing gradient text ("215%")
- Studio-shot agency team in matching black t-shirts

### What signals premium and trust in this category
- Real photography of real, named local clients
- Founder portrait in a real setting (not studio)
- Editorial restraint — generous whitespace, calm typography
- Specific data callouts with context (not generic upward arrows)
- Process diagrams that explain the actual stack
- Local geographic anchors (PCMC streetscapes, recognizable Ravet/Pune cues)
- Clean infographic with hierarchy, not decoration

### What visual gap exists in PCMC right now
A **deeply local, AI-native, editorially restrained** look. Most PCMC agencies oscillate between Justdial-tier visual clutter and Bombay-import minimalism that feels foreign. Neither owns the middle.

> Strategic recommendation: anchor Digitech in **modern editorial + locally rooted + restrained AI-forward** — the look of a smart Pune-based growth firm, not a global SaaS brand and not a freelancer.

## SECTION 5 — TYPOGRAPHY STYLE

🟦 Stage 2 refinement note: typography recommendations below avoid the Avenir/Poppins/Montserrat clichés flagged in Prompt 01. Final pairing locks with founder preference after seeing reference designs.

### 5.1 — Recommended primary type pairing

**Headline font:** Space Grotesk *(or Inter Display as alternative)*
- Why: Modern, geometric, slightly tech-forward — matches the "AI-native" positioning. Confident without being aggressive. Reads well in navy or white.
- Weights to use: 500 Medium · 600 Semibold · 700 Bold
- Substitutes if unavailable: General Sans, Söhne, Geist

**Body font:** Inter *(or IBM Plex Sans as alternative)*
- Why: Best-in-class readability on mobile (critical for India SMB audience); pairs naturally with Space Grotesk; supports Devanagari extension if Marathi/Hindi needed
- Weights to use: 400 Regular · 500 Medium · 600 Semibold
- Substitutes if unavailable: -apple-system, Segoe UI, Helvetica Neue

**Accent / display (optional):** Fraunces *(serif contrast for editorial quote pulls only)*
- Use sparingly — for testimonials, case-study openers, or one-line statement slides

### 5.2 — Type scale (desktop)

| Element | Font | Weight | Size | Line height | Letter spacing |
|---|---|---|---|---|---|
| H1 — Hero | Space Grotesk | 600 | 56px | 1.1 | -0.02em |
| H2 — Section | Space Grotesk | 600 | 40px | 1.15 | -0.015em |
| H3 — Sub | Space Grotesk | 500 | 28px | 1.25 | -0.01em |
| H4 — Card title | Space Grotesk | 500 | 20px | 1.3 | 0 |
| Body Large | Inter | 400 | 18px | 1.6 | 0 |
| Body | Inter | 400 | 16px | 1.6 | 0 |
| Caption | Inter | 500 | 13px | 1.5 | 0.01em |
| CTA button | Space Grotesk | 600 | 16px | 1 | 0.02em |
| Footer | Inter | 400 | 14px | 1.5 | 0 |

### 5.3 — Type scale (mobile)

| Element | Size |
|---|---|
| H1 — Hero | 36px |
| H2 — Section | 28px |
| H3 — Sub | 22px |
| H4 — Card title | 18px |
| Body Large | 17px |
| Body | 16px |
| Caption | 12px |
| CTA button | 16px |

### 5.4 — Typography rules

- **One H1 per page / one main headline per post.** No "double-hero" stacking.
- **Headlines in navy on white.** Yellow headlines only on dark navy background.
- **Body never below 16px on web, never below 28px on social creatives** (Indian mobile audience scrolls fast — readability is non-negotiable).
- **Emphasis = weight, not color.** Use 600/700 for emphasis. Reserve color emphasis (yellow underline, green dot) for one item per composition.
- **Sentence case in headlines** ("How we onboard a client in 7 days"), not Title Case. Feels conversational, not corporate.
- **Numbers: tabular nums on.** Specific in stats. Avoid generic "200%" hype-style display numerals.

### 5.5 — Typography "do nots"

- 🚨 Never Poppins, Montserrat, or Roboto as a primary — visual category cliché
- 🚨 Never serifs as a primary headline (Fraunces is accent-only)
- 🚨 Never all-caps body text — fails readability for the audience
- 🚨 Never headlines in pure yellow on white — fails contrast
- ⚠️ Never more than 2 fonts active in any single composition

## SECTION 6 — LAYOUT PRINCIPLES

### 6.1 — Grid system

🟦 **12-column grid** for web. **8-column grid** for social creatives (works for square, portrait, and story formats).

### 6.2 — Spacing rhythm (8px baseline)

| Token | Pixels | Usage |
|---|---|---|
| xs | 4 | Tight icon-to-label gaps |
| sm | 8 | Tight inline elements |
| md | 16 | Default content gap |
| lg | 24 | Section internal padding |
| xl | 40 | Component separation |
| 2xl | 64 | Section breaks |
| 3xl | 96 | Page-level breaks |

### 6.3 — Composition philosophy

- **Generous whitespace.** Crowded design = cheap. Restraint = premium.
- **Single focal point per composition.** One headline, one main visual, one CTA. Everything else recedes.
- **Hierarchy by size + weight, not by color.** Color is the punctuation, not the hierarchy.
- **Asymmetric balance preferred over centered symmetry.** Editorial feel.
- **Left-aligned text by default.** Centered only for hero declarations.

### 6.4 — Safe zones per format

| Format | Safe zone |
|---|---|
| Instagram square (1080×1080) | 80px from all edges |
| Instagram portrait (1080×1350) | 80px from sides, 120px top, 200px bottom (for caption preview) |
| Story (1080×1920) | 220px from top (avoid profile area), 350px from bottom (avoid UI controls) |
| Reel cover (1080×1920) | Center 60% — cropped on grid view |
| LinkedIn banner (1200×628) | 80px from all edges |
| Ad creative (any) | Same as base format; never let text touch the safe-zone line |

### 6.5 — The "data tile" motif (✅ derived from logo)

The logo's defining graphic device is the **square-dot pattern** that builds the globe. Use this as a recurring visual element:

- Background pattern (subtle, low-opacity tile grid)
- Section dividers (a single row of tiles, navy → fading to white)
- Data viz (charts built from tile units, not generic lines)
- Loading / progress indicators (tile fill animation on web)
- Numerical callouts (number set in a tile-pattern background)

Use the tile motif **with restraint** — it's a signature device, not wallpaper. Maximum once per creative.

## SECTION 10 — CTA BUTTON STYLE

### 10.1 — Primary CTA

- **Shape:** Rectangle with **4px corner radius** (slight rounding, not pill-shape, not sharp)
- **Background:** Solutions Yellow `#FFC72C` 🔍
- **Text:** Digitech Navy `#0A1F44` 🔍 — Space Grotesk 600 — 16px — letter-spacing 0.02em
- **Padding:** 14px vertical · 28px horizontal
- **Hover state (web):** Darken yellow by 8%, navy text unchanged
- **Icon (optional):** Right-side arrow (lucide `arrow-right`) — 16px, same color as text, 8px from text
- **Shadow:** Subtle — `0 2px 8px rgba(10, 31, 68, 0.12)` — no glow, no neon

### 10.2 — Secondary CTA

- **Shape:** Same as primary
- **Background:** Transparent
- **Border:** 1.5px solid Digitech Navy
- **Text:** Digitech Navy, same type spec as primary
- **Hover:** Background fills to Cloud Tint `#F5F7FA`

### 10.3 — Ghost / inline CTA

- No border, no background
- Text in Digitech Navy with underline
- Used for "Learn more →" style inline links inside body copy

### 10.4 — Disabled state

- 40% opacity on the primary button
- Cursor: not-allowed
- Removes shadow

### 10.5 — Approved CTA copy

✅ Use these:
- "Start Project"
- "Get Free Audit"
- "Book a 30-min Call"
- "See Our Work"
- "WhatsApp Us"
- "Get the Plan"
- "Talk to Vishwajit"

🚨 Do not use:
- "Click here"
- "Submit"
- "Buy now" (wrong tone)

## SECTION 13 — SOCIAL MEDIA DESIGN STYLE TYPES

All 13 approved types. Each spec includes use case, design rules, and watch-outs.

### 13.1 — Photorealistic

**Use case:** Founder portraits, real client features, team behind-the-scenes, real PCMC client environments.

**Rules:**
- Real photography only (or photoreal AI per `AI_Prompting_Guide`)
- Natural lighting, warm tones
- Headline in white on a darkened bottom-overlay strip
- Logo bottom-right
- Single one-line headline, max 12 words

**Watch-outs:** Avoid stock photo aesthetics; avoid heavy filters; avoid AI artifacts (extra fingers, weird text).

---

### 13.2 — Light background

**Use case:** Educational posts, infographics, service explainers — default workhorse style.

**Rules:**
- Background: White or Cloud Tint `#F5F7FA`
- Headline: Navy, Space Grotesk 600
- One supporting visual or illustration, navy + yellow palette
- Yellow underline or yellow dot as single accent
- Footer strip in navy

**Watch-outs:** Don't fill with multiple competing accents; keep one focal point.

---

### 13.3 — Dark background

**Use case:** Premium / authority posts, founder POV content, "we vs them" comparisons, AI-native showcases.

**Rules:**
- Background: Digitech Navy `#0A1F44` 🔍 or Deep Navy `#061633`
- Headline: White or Yellow
- Body text: White or Mist Gray
- Yellow as the single accent — used for one word emphasis or one underline
- Optional: subtle data-tile background pattern at 5–8% opacity

**Watch-outs:** Don't use multicolor "D" gradient on dark — it muddies. Don't stack green + yellow on dark — it gets carnival-y.

---

### 13.4 — Infographic

**Use case:** Process explainers, "how X works", comparison charts, stat-led posts.

**Rules:**
- Strong hierarchy: 1 title + 3–5 numbered or labeled blocks
- Block dividers using the data-tile motif
- Numbers in large Space Grotesk 700, yellow on navy or navy on white
- Icons in navy line-style (Lucide)
- Max 6 callouts; each callout text 4–8 words

**Watch-outs:** Don't try to fit 8+ data points; if data is dense, split into a carousel.

---

### 13.5 — Info + photorealistic

**Use case:** Case study openers, founder explainer carousels, "here's what we did for X" wins.

**Rules:**
- Top 50% photorealistic image (real client / real team / real environment)
- Bottom 50% info block on white or navy
- Information area: 1 stat + 1 supporting line + logo
- Brand accent line (yellow, 2px) separates the two zones

**Watch-outs:** Make sure the photo has enough negative space so type doesn't fight the subject.

---

### 13.6 — Text heavy 50%

**Use case:** Founder POV, opinion posts, observations, micro-blog-style.

**Rules:**
- 50% of canvas = type (headline + 3–4 short body lines)
- 50% = whitespace or a single subtle visual (icon, data tile pattern, photo strip)
- Headline 36–44px, body 18–22px
- Max 60–100 words total

**Watch-outs:** Don't justify text; left-align always. Don't squeeze in extra lines.

---

### 13.7 — Text heavy 75%

**Use case:** Quote pulls, long-form opinion, "things we believe" manifesto-style posts.

**Rules:**
- 75% type, 25% supporting element (logo strip, accent, signature)
- Use Fraunces serif for the body if it's a quote pull
- Single yellow underline or accent dot for one phrase
- Max 100–160 words

**Watch-outs:** Keep generous line-height (1.5–1.6). Never set body below 24px on a creative.

---

### 13.8 — Text heavy 100%

**Use case:** Statement posts, declarations, "we stand for" posts, manifesto slides in a carousel.

**Rules:**
- Full-canvas text composition
- Hierarchy: 1 hero line (huge, 64–80px on portrait format), 0–1 sub line, signature
- Background: Navy or Yellow (very rarely)
- Type fills the canvas with intentional whitespace around it

**Watch-outs:** This style needs the most editorial discipline — one wrong word kills the whole composition.

---

### 13.9 — Festival / occasion post

**Use case:** Diwali, Holi, Ganesh Chaturthi, Independence Day, Republic Day, Marathi New Year, Gudi Padwa, year-end wraps.

**Rules:**
- Brand colors dominant (navy + yellow + white)
- One festival-relevant graphic element (diya outline, rangoli detail, single flag stroke)
- Festival greeting in regional language **and** English where appropriate
- Headline restrained — never "MEGA SALE THIS DIWALI"
- Footer with brand name + city only

**Watch-outs:** Never overdo motifs. Never overlay logo on a deity image. Never use Diwali as a sales ad — separate cultural and commercial posts.

---

### 13.10 — Offer / ad creative

**Use case:** Lead-gen ads, free-audit promos, consult-call CTAs running on Meta / Google.

**Rules:**
- Strong headline: Problem or Promise in 6–10 words
- Single visual proof element (number, before-after, testimonial quote)
- CTA prominent in lower third (Solutions Yellow button)
- Brand footer thin and minimal — let the offer dominate
- Compliance: any claim must be backed (no "guaranteed leads")

**Watch-outs:** Don't over-stuff. Don't run "Book Now Limited Time" urgency — feels low-trust for this audience.

---

### 13.11 — Promotional

**Use case:** Service-launch announcements, new package launches, GMB-management package promos.

**Rules:**
- Same as Offer creative but softer urgency
- Headline: name of the service + 1-line benefit
- 3 supporting bullets max
- CTA + WhatsApp number
- Brand footer standard

---

### 13.12 — Carousel cover

**Use case:** First slide of any educational, opinion, case-study, or list carousel.

**Rules:**
- 1080×1350 portrait (Instagram preferred)
- Big headline (44–56px) — hook + curiosity
- "Swipe →" indicator bottom-right
- Logo bottom-left at 5–6% canvas height
- Background: Navy or White (both work; Navy converts better for opinion/POV)
- Hook formulas (use any):
  - "Why most PCMC agencies look the same"
  - "How we onboard a client in 7 days"
  - "5 things broken on your GMB right now"
  - "The honest cost of digital marketing in Pune"

**Watch-outs:** No more than 12 words on the cover. Test legibility at thumbnail size.

---

### 13.13 — Educational carousel slide

**Use case:** Middle slides of any educational carousel.

**Rules:**
- Slide number top-right (small, navy, "02 / 07")
- One concept per slide
- Headline + 30–60 words of body
- One supporting visual (icon, mini-chart, illustration)
- Consistent navigation between slides (same grid position for headline, same logo placement, same slide-number style)
- Penultimate slide: summary / 3-bullet recap
- Final slide: CTA + WhatsApp + handle

**Watch-outs:** Maintain visual rhythm across slides — every slide should feel part of the same set. No "design experiments" on slide 4.

## SECTION 14 — STRONG DO AND DON'T RULES

### Do ✅
- Lock to navy + yellow + green palette derived from logo
- Use white space generously — restraint is the brand
- Show real people (team, clients, founder) over stock
- Anchor every creative in PCMC / Pune local relevance where possible
- Use the data-tile motif as a signature device (sparingly)
- Lead with one clear focal point per creative
- Keep type hierarchy clear: size + weight before color
- Show specific numbers (named clients, real results) — never generic "200%"
- Use Marathi / Hindi when culturally relevant — never as decoration
- Test legibility at thumbnail size before publishing

### Don't 🚨
- Don't use cyan/purple "AI gradient" anywhere — it's the category cliché we're escaping
- Don't use Poppins / Montserrat / Roboto as primary
- Don't stack the multicolor "D" gradient over backgrounds (it's punctuation, not pattern)
- Don't use stock-photo team huddles, laptops, or "diverse hands"
- Don't use "No.1", "best in Pune", "world-class" — empty claims
- Don't overuse rocket / megaphone / trophy icons
- Don't run sales-y urgency ("Limited time! Last 3 spots!") — wrong audience
- Don't put logo on yellow background (wordmark disappears)
- Don't justify body text — left-align only
- Don't crowd a single creative with more than 3 message points
- Don't break the safe-zone rules — preview every creative on phone before publishing
- Don't use AI-generated faces of people who don't exist for "client testimonials"

## SECTION 15 — INDUSTRY COMPLIANCE NOTES

The Digitech Solutions itself is a marketing agency — direct compliance constraints are minimal. **But the client serves regulated verticals**, so creative for hospital / political / education / real estate clients must respect their compliance frameworks.

### 15.1 — When designing creatives for Digitech's brand itself

- ✅ Safe to claim: specific verifiable wins (with permission), founded year, team size, services offered, location
- 🚨 Avoid claims that need substantiation we don't have: "No.1", "Award-winning" (unless named award is shown), "ISO certified" (unless held), "Trusted by 500+" (currently inconsistent — fix per Prompt 01 🚨)
- 🔍 Existing site claim "215% conversion / 47% cost reduction" — must be sourced or removed in new creatives

### 15.2 — When designing creatives FOR Digitech's clients (downstream)

This affects future skill files, not this document directly. Flagged for downstream skill development:

- **Healthcare clients:** NMC, MMC, ASCI, Drugs & Magic Remedies Act compliance — no before/after promises, no "guaranteed cure", no doctor recommendations without disclaimer (handled by future healthcare niche overlay)
- **Real estate clients:** RERA disclosure on any project promo
- **Political clients:** ECI guidelines around silence periods, paid promotion disclosure
- **Education clients:** No misleading admission / placement claims

### 15.3 — General disclaimers (recommended)

For lead-gen / offer creatives on Digitech's own brand:
- "Results vary by business and market conditions"
- "Free audit valid for businesses based in PCMC / Pune"
